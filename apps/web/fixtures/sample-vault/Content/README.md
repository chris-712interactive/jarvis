# Content drafts

Daily Skool / Instagram / channel drafts land here when a lane has:
- content channel set (e.g. `skool` or `instagram`)
- daily content on
- a vault path

For `instagram`, Jarvis also writes a sibling `.png` next to the markdown note.

Workflow: Jarvis drafts → **Needs you** → copy into the channel (or **Approve & publish** for Instagram when Meta Graph is configured) → Resolve.
